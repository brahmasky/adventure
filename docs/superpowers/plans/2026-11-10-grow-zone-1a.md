# Grow Zone 1a Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Houge writes a prose skill through one door, code-owned checks and a different-family reviewer decide whether it goes live, with no build, no restart and no human gate; the old skill-author pipeline is removed.

**Architecture:** A new protected module `src/grow/` owns a separate local git repository (the grow zone). The planner reaches it only through two bridge tools: `grow_submit` (content as arguments → formal checks → staged in SQLite → small updates publish at once, everything else is reviewed after the turn by a one-shot `grow_review` seat) and `grow_read` (committed text from HEAD; a born-untrusted item raises turn trust). The system prompt carries an alphabetical index instead of skill bodies; outcomes and recurrence hints reach the planner as per-turn `[context]` lines.

**Tech Stack:** Node 22 + TypeScript, `node:sqlite` through `RunStore`, `git` through `src/run/git-hardened.ts`, omp one-shot seats (`spawnOneShot`), vitest. Zero runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-11-10-grow-zone-verification-design.md` (Rev 1.3.1, approved by Paco 2026-11-10). Executors read both. Where this plan and the spec differ, the plan-time errata in spec §15 say which wins.

## Global Constraints

- `dependencies: {}` stays empty. Node stdlib and devDeps only.
- Functions under 50 lines. Match surrounding style. Handle errors explicitly; no silent failure.
- Never call `os.tmpdir()` in `src/` (tests may). Daemon temp files go through `src/run/daemon-tmp.ts`.
- Daemon-side git only through `hardenedGit` (`src/run/git-hardened.ts`); never `execFileSync("git")` in `src/`.
- Every new `HOUGE_*` name that appears anywhere in `src/` (comments included) needs a row in `docs/reference/configuration.md` in the same commit (`tests/docs/parity.test.ts`). A name ending in `_ENABLED` must be in `DISARM_FLAGS` or the ADR 0034 test fails.
- Every new bridge tool name must appear as `` `name` `` in `README.md`; every new `command === "/x"` in the parser must appear as `` `/x `` in `README.md`.
- Telegram replies are markdown text in a `reply` notification (`replyTo` in `src/gateway/memory-commands.ts`); no headings, use `**bold**`.
- Logs carry error codes (`errorCode(error)`), never message or skill text. Ledger rows carry counts and hashes, never a skill body.
- Time is injected (`now: string`); no `Date.now()` in latch or backoff logic.
- Caps, verbatim from the spec: name `[a-z0-9-]{3,48}`; description 20–200 chars; example 10–300 chars; body 200–8,000 chars; serialized submit ≤ 16 KB; 20 submits per rolling 24 h; 200 live items; index ≤ 40 lines and ≤ 4,000 chars; small update = ≤ 20 changed lines and ≤ 25 % of body lines, `description` and `example` unchanged; review retries at +1 h, +6 h, +24 h, then `review_unavailable`; a claim is stale after 10 minutes; hints ≤ 3 per rolling 24 h.
- Work happens in a worktree: `.worktrees/grow-zone-1a`, branch `grow-zone-1a`. Verify each task with `npm run typecheck && npx vitest run <files>`; run the full `npm run typecheck && npm test && npm run build` at the end of Tasks 8, 13 and 14.
- Commits: Conventional Commits, one concern each, files staged by name, ending with the attribution lines from the session reminder.
- Every subagent dispatch names its `model`; a task's reviewer is a different model from its implementer.

/** Grow zone 1a (spec 2026-11-10 §5.13): git holds content; these hold state, origin, uses, reasons, the review queue and hints. */
const GROW_DDL = `
  CREATE TABLE IF NOT EXISTS grow_items (
    name TEXT PRIMARY KEY, state TEXT NOT NULL CHECK (state IN ('live','removed','orphan')),
    origin TEXT NOT NULL CHECK (origin IN ('clean','untrusted','exemplar')),
    description TEXT NOT NULL, example TEXT NOT NULL, uses INTEGER NOT NULL DEFAULT 0, last_used_at TEXT,
    head_commit TEXT, content_hash TEXT NOT NULL, created_at TEXT NOT NULL, updated_at TEXT NOT NULL);
  CREATE TABLE IF NOT EXISTS grow_staged (
    id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL, run_id TEXT, chat_id TEXT,
    origin TEXT NOT NULL CHECK (origin IN ('clean','untrusted','exemplar')),
    fields_json TEXT NOT NULL, content_hash TEXT NOT NULL, needs_review INTEGER NOT NULL,
    state TEXT NOT NULL CHECK (state IN ('staged','publishing','failed')),
    attempts INTEGER NOT NULL DEFAULT 0, claimed_at TEXT, next_attempt_at TEXT, author_families TEXT,
    code TEXT, findings_json TEXT, review_input_hash TEXT, created_at TEXT NOT NULL, updated_at TEXT NOT NULL);
  CREATE INDEX IF NOT EXISTS grow_staged_state_idx ON grow_staged(state, next_attempt_at);
  CREATE TABLE IF NOT EXISTS grow_events (
    id INTEGER PRIMARY KEY AUTOINCREMENT, at TEXT NOT NULL, run_id TEXT, chat_id TEXT, name TEXT NOT NULL,
    action TEXT NOT NULL CHECK (action IN ('submit','publish','review_failed','undo','read','hint','seed','migrate','trust','adopt')),
    result TEXT NOT NULL, code TEXT, reviewer_model TEXT, commit_id TEXT);
  CREATE INDEX IF NOT EXISTS grow_events_action_at_idx ON grow_events(action, at);
  CREATE UNIQUE INDEX IF NOT EXISTS grow_events_read_once_idx ON grow_events(run_id, name) WHERE action = 'read';
  CREATE TABLE IF NOT EXISTS grow_undo_reasons (id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL, at TEXT NOT NULL, reason TEXT NOT NULL);
  CREATE TABLE IF NOT EXISTS grow_context_cursor (chat_id TEXT PRIMARY KEY, last_event_id INTEGER NOT NULL);
  CREATE TABLE IF NOT EXISTS grow_hints (
    idempotency_key TEXT PRIMARY KEY, chat_id TEXT, category TEXT NOT NULL, turn_ids_json TEXT NOT NULL,
    decision_id TEXT NOT NULL, created_at TEXT NOT NULL);
`;

Add the three row interfaces from **Interfaces** beside the mail row types, and the methods beside the mail methods. `needs_review` is stored as 0/1: map it with a private `toGrowStaged(r)` exactly as `toMailItem` maps booleans. The non-obvious ones, verbatim:

```ts
  claimGrowReview(id: number, now: string): boolean {
    const r = this.db.prepare(`UPDATE grow_staged SET claimed_at = ?, attempts = attempts + 1, updated_at = ? WHERE id = ? AND state = 'staged' AND claimed_at IS NULL`).run(now, now, id);
    return Number(r.changes) === 1;
  }
  releaseStaleGrowClaims(staleBefore: string): number {
    return Number(this.db.prepare(`UPDATE grow_staged SET claimed_at = NULL WHERE state = 'staged' AND claimed_at IS NOT NULL AND claimed_at < ?`).run(staleBefore).changes);
  }
  recordGrowUse(name: string, run_id: string, now: string): boolean {
    return this.joinTransaction(() => {
      const r = this.db.prepare(`INSERT OR IGNORE INTO grow_events (at, run_id, chat_id, name, action, result) VALUES (?, ?, NULL, ?, 'read', 'ok')`).run(now, run_id, name);
      if (Number(r.changes) === 0) return false;
      this.db.prepare(`UPDATE grow_items SET uses = uses + 1, last_used_at = ? WHERE name = ?`).run(now, name);
      return true;
    });
  }
  recordGrowHint(i: { idempotency_key: string; chat_id: string | null; category: string; turn_ids: string[]; decision_id: string; now: string }): boolean {
    return this.joinTransaction(() => {
      const r = this.db.prepare(`INSERT OR IGNORE INTO grow_hints (idempotency_key, chat_id, category, turn_ids_json, decision_id, created_at) VALUES (?, ?, ?, ?, ?, ?)`)
        .run(i.idempotency_key, i.chat_id, i.category, JSON.stringify(i.turn_ids), i.decision_id, i.now);
      if (Number(r.changes) === 0) return false;
      this.appendGrowEvent({ at: i.now, run_id: null, chat_id: i.chat_id, name: "-", action: "hint", result: "ok", code: i.category, reviewer_model: null, commit_id: null });
      return true;
    });
  }
  growHintOverlapsTurns(turn_ids: string[], since: string): boolean {
    const wanted = new Set(turn_ids);
    return this.db.prepare(`SELECT turn_ids_json FROM grow_hints WHERE created_at >= ?`).all<{ turn_ids_json: string }>(since)
      .some((r) => (JSON.parse(r.turn_ids_json) as string[]).some((t) => wanted.has(t)));
  }
  runAuthorFamilies(run_id: string): { families: string[]; unknown: boolean } {
    const rows = this.db.prepare(`SELECT json_extract(payload_json,'$.family') AS family FROM ledger_events
      WHERE run_id = ? AND event_type = 'llm_attempt' AND json_extract(payload_json,'$.role') = 'compose' AND json_extract(payload_json,'$.outcome') = 'ok'`).all<{ family: string | null }>(run_id);
    const families = [...new Set(rows.map((r) => r.family).filter((f): f is string => typeof f === "string" && f.length > 0))].sort();
    return { families, unknown: rows.length === 0 || rows.some((r) => !r.family) };
  }
```

```ts
import { createHash } from "node:crypto";

export interface GrowFields { name: string; description: string; example: string; body: string; anchors?: string[] }
export type GrowOrigin = "clean" | "untrusted" | "exemplar";
export type GrowFailCode = "bad_name" | "bad_description" | "bad_example" | "bad_body" | "bad_anchors" | "too_large" | "control_chars" | "secret_shape" | "needs_script" | "duplicate";
export type CheckResult = { ok: true } | { ok: false; code: GrowFailCode; message: string };

export const GROW_LIMITS = { nameRe: /^[a-z0-9-]{3,48}$/, descMin: 20, descMax: 200, exampleMin: 10, exampleMax: 300, bodyMin: 200, bodyMax: 8000,
  totalMax: 16_384, anchorsMax: 8, anchorMax: 300, smallLines: 20, smallShare: 0.25 } as const;
export const EXEMPLAR_HINT = "see the exemplar weekly-digest-brief (grow_read it) for the expected shape";

const fail = (code: GrowFailCode, message: string): CheckResult => ({ ok: false, code, message: `${message}; ${EXEMPLAR_HINT}` });
const oneLine = (s: string, min: number, max: number): boolean => s.length >= min && s.length <= max && !/[\r\n]/.test(s);
// eslint-disable-next-line no-control-regex
const CONTROL = /[\u0000-\u0008\u000b\u000c\u000e-\u001f\u007f]/;
const norm = (s: string): string => s.trim().toLowerCase().replace(/\s+/g, " ");
const texts = (f: GrowFields): string[] => [f.name, f.description, f.example, f.body, ...(f.anchors ?? [])];

function shape(f: GrowFields): CheckResult {
  const L = GROW_LIMITS;
  if (!L.nameRe.test(f.name)) return fail("bad_name", "name must be 3-48 chars of a-z, 0-9 and hyphen");
  if (!oneLine(f.description, L.descMin, L.descMax)) return fail("bad_description", "description must be one line of 20-200 chars saying when to use the skill");
  if (!oneLine(f.example, L.exampleMin, L.exampleMax)) return fail("bad_example", "example must be one line of 10-300 chars: a request this skill answers");
  if (f.body.length < L.bodyMin || f.body.length > L.bodyMax) return fail("bad_body", "body must be 200-8000 chars");
  const a = f.anchors ?? [];
  if (a.length > L.anchorsMax || a.some((x) => !oneLine(x, 1, L.anchorMax))) return fail("bad_anchors", "anchors must be at most 8 single lines of at most 300 chars");
  if (Buffer.byteLength(JSON.stringify(f), "utf8") > L.totalMax) return fail("too_large", "the submission exceeds 16 KB");
  return { ok: true };
}

/** A fenced block of more than three inner lines: an exact procedure belongs in a script, which 1a does not accept. */
function longFence(body: string): boolean {
  let open = -1;
  const lines = body.split("\n");
  for (let i = 0; i < lines.length; i++) {
    if (!lines[i]!.trimStart().startsWith("```")) continue;
    if (open === -1) { open = i; continue; }
    if (i - open - 1 > 3) return true;
    open = -1;
  }
  return open !== -1 && lines.length - open - 1 > 3;
}

export function checkFields(f: GrowFields, live: ReadonlyArray<{ name: string; description: string; content_hash: string }>, scrub: (s: string) => string): CheckResult {
  const s = shape(f);
  if (!s.ok) return s;
  if (texts(f).some((t) => CONTROL.test(t))) return fail("control_chars", "a field contains control characters");
  if (texts(f).some((t) => scrub(t) !== t)) return { ok: false, code: "secret_shape", message: "a field contains something shaped like a secret or a secret path; remove it" };
  if (longFence(f.body)) return fail("needs_script", "a fenced block longer than three lines needs a script, and scripts arrive in a later slice; describe the steps in prose");
  const hash = contentHash(f);
  const twin = live.find((x) => x.name !== f.name && (norm(x.description) === norm(f.description) || x.content_hash === hash));
  return twin ? fail("duplicate", `the live skill ${twin.name} already covers this; update that one`) : { ok: true };
}

export function isSmallUpdate(prev: GrowFields, next: GrowFields): boolean {
  if (prev.description !== next.description || prev.example !== next.example) return false;
  if (JSON.stringify(prev.anchors ?? []) !== JSON.stringify(next.anchors ?? [])) return false;
  const a = prev.body.split("\n"); const b = next.body.split("\n");
  const count = (xs: string[]): Map<string, number> => xs.reduce((m, x) => m.set(x, (m.get(x) ?? 0) + 1), new Map<string, number>());
  const left = count(a);
  let added = 0;
  for (const line of b) { const n = left.get(line) ?? 0; if (n > 0) left.set(line, n - 1); else added += 1; }
  const removed = [...left.values()].reduce((x, y) => x + y, 0);
  const changed = Math.max(added, removed);
  return changed <= GROW_LIMITS.smallLines && changed <= Math.floor(Math.max(a.length, b.length) * GROW_LIMITS.smallShare);
}

export function renderSkillFile(f: GrowFields, origin: GrowOrigin): string {
  const anchors = (f.anchors ?? []).length > 0 ? `anchors:\n${f.anchors!.map((a) => `  - ${JSON.stringify(a)}`).join("\n")}\n` : "";
  return `---\nname: ${f.name}\ndescription: ${JSON.stringify(f.description)}\nexample: ${JSON.stringify(f.example)}\norigin: ${origin}\n${anchors}---\n\n${f.body}\n`;
}

const str = (raw: string): string | null => { try { const v: unknown = JSON.parse(raw); return typeof v === "string" ? v : null; } catch { return null; } };

export function parseSkillFile(text: string): (GrowFields & { origin: GrowOrigin }) | null {
  const m = /^---\n([\s\S]*?)\n---\n\n([\s\S]*)\n$/.exec(text);
  if (!m) return null;
  const head = m[1]!; const body = m[2]!;
  const line = (k: string): string | undefined => new RegExp(`^${k}: (.*)$`, "m").exec(head)?.[1];
  const name = line("name"); const description = str(line("description") ?? ""); const example = str(line("example") ?? ""); const origin = line("origin");
  if (!name || description === null || example === null || (origin !== "clean" && origin !== "untrusted" && origin !== "exemplar")) return null;
  const anchors = [...head.matchAll(/^ {2}- (.*)$/gm)].map((x) => str(x[1]!)).filter((x): x is string => x !== null);
  return { name, description, example, body, ...(anchors.length > 0 ? { anchors } : {}), origin };
}

export function contentHash(f: GrowFields): string {
  return createHash("sha256").update(JSON.stringify([f.name, f.description, f.example, f.body, f.anchors ?? []])).digest("hex");
}

```ts
import { existsSync, mkdirSync, realpathSync, renameSync, rmSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { hardenedGit } from "../run/git-hardened.js";
import { GROW_LIMITS } from "./checks.js";

export class GrowZoneError extends Error {
  constructor(readonly code: "not_toplevel" | "git_failed" | "bad_name") { super(code); }
}
export const skillPath = (name: string): string => `skills/${name}/SKILL.md`;
const IDENTITY = ["-c", "user.name=Houge", "-c", "user.email=houge@localhost", "-c", "commit.gpgsign=false"];
const GIT_TIMEOUT_MS = 20_000;

/** The grow zone's git repository (spec §5.1). Every call names the git dir and work tree, and never inherits a GIT_* variable. */
export class GrowZone {
  constructor(readonly dir: string, private readonly opts: { signal?: AbortSignal } = {}) {}

  private async git(args: string[]): Promise<string> {
    const env = { PATH: process.env.PATH ?? "/usr/bin:/bin", HOME: process.env.HOME ?? "", GIT_CEILING_DIRECTORIES: dirname(this.dir) };
    try {
      const r = await hardenedGit(["--git-dir", join(this.dir, ".git"), "--work-tree", this.dir, ...IDENTITY, ...args],
        { env, cwd: this.dir, timeout: GIT_TIMEOUT_MS, maxBuffer: 4 * 1024 * 1024, ...(this.opts.signal ? { signal: this.opts.signal } : {}) });
      return r.stdout;
    } catch { throw new GrowZoneError("git_failed"); }
  }

  async ensure(): Promise<void> {
    mkdirSync(join(this.dir, "skills"), { recursive: true });
    if (!existsSync(join(this.dir, ".git"))) {
      await this.git(["init", "-q", "-b", "main"]);
      await this.git(["commit", "-q", "--allow-empty", "-m", "grow zone"]);
    }
    await this.assertToplevel();
  }

  async assertToplevel(): Promise<void> {
    if (!existsSync(join(this.dir, ".git"))) throw new GrowZoneError("not_toplevel");
    const top = (await this.git(["rev-parse", "--show-toplevel"])).trim();
    if (realpathSync(top) !== realpathSync(this.dir)) throw new GrowZoneError("not_toplevel");
  }

  async head(): Promise<string> { return (await this.git(["rev-parse", "HEAD"])).trim(); }

  async readHead(name: string): Promise<string | null> {
    this.checkName(name);
    try { return await this.git(["show", `HEAD:${skillPath(name)}`]); } catch { return null; }
  }

  async listHead(): Promise<string[]> {
    const out = await this.git(["ls-tree", "-r", "--name-only", "HEAD", "--", "skills"]);
    return out.split("\n").map((p) => /^skills\/([a-z0-9-]+)\/SKILL\.md$/.exec(p)?.[1]).filter((n): n is string => n !== undefined).sort();
  }

  async writeAndCommit(name: string, text: string, message: string): Promise<string> {
    this.checkName(name);
    await this.assertToplevel();
    const file = join(this.dir, skillPath(name));
    mkdirSync(dirname(file), { recursive: true });
    writeFileSync(`${file}.tmp`, text);
    renameSync(`${file}.tmp`, file);
    await this.git(["add", "--", skillPath(name)]);
    await this.git(["commit", "-q", "--allow-empty", "-m", message]);
    return this.head();
  }

  async removeAndCommit(name: string, message: string): Promise<string> {
    this.checkName(name);
    await this.assertToplevel();

  }

    await this.assertToplevel();

    try {
      await this.git(["bundle", "create", "-q", tmp, "--all"]);
      await this.git(["bundle", "verify", "-q", tmp]);
      renameSync(tmp, toPath);
    } catch (e) { rmSync(tmp, { force: true }); throw e; }
  }

    if (!GROW_LIMITS.nameRe.test(name)) throw new GrowZoneError("bad_name");
  }

```ts
export class GrowService {
  private busy = false;
  private disabled: string | null = null;
  private readonly shown = new Map<string, { chat_id: string; last: number }>();
  constructor(private readonly d: GrowDeps) {}

  disabledReason(): string | null { return this.disabled; }

  /** One writer at a time across the zone and its tables; a second caller is told, never queued (spec §5.8). */
  private async locked<T>(fn: () => Promise<T>, whenBusy: T): Promise<T> {
    if (this.busy) return whenBusy;
    this.busy = true;
    try { return await fn(); } finally { this.busy = false; }
  }

  async submit(f: GrowFields, ctx: SubmitCtx): Promise<SubmitResult> {
    if (!resolveGrowEnabled(this.d.env)) return refused("grow_disabled");
    if (this.disabled) return refused("zone_unavailable");
    if (ctx.level === "hostile") return refused("turn_hostile");
    return this.locked(() => this.submitLocked(f, ctx), refused("busy"));
  }

  private async submitLocked(f: GrowFields, ctx: SubmitCtx): Promise<SubmitResult> {
    const { store } = this.d; const now = this.d.now();
    const existing = store.getGrowItem(f.name);
    if (existing?.origin === "exemplar") return refused("name_is_exemplar");
    if (store.countGrowEventsSince("submit", new Date(Date.parse(now) - DAY_MS).toISOString()) >= GROW_SUBMITS_PER_DAY) return refused("rate_capped");
    if (!existing && store.countGrowItems("live") >= GROW_ITEMS_MAX) return refused("zone_full");
    const check = checkFields(f, store.listGrowItems("live"), (s) => redactForImprove(store, s));
    store.appendGrowEvent({ at: now, run_id: ctx.run_id, chat_id: ctx.chat_id, name: f.name, action: "submit", result: check.ok ? "accepted" : "failed", code: check.ok ? null : check.code, reviewer_model: null, commit_id: null });
    if (!check.ok) return { status: "FAIL", code: check.code, message: check.message };
    const origin: GrowOrigin = existing?.state === "live" && existing.origin === "untrusted" ? "untrusted" : ctx.level === "untrusted" ? "untrusted" : "clean";
    const needs_review = await this.needsReview(f, existing?.state === "live", origin);
    const id = store.insertGrowStaged({ name: f.name, run_id: ctx.run_id, chat_id: ctx.chat_id, origin, fields_json: JSON.stringify(f), content_hash: contentHash(f), needs_review, now });
    if (needs_review) return { status: "STAGED", name: f.name };
    return (await this.publishLocked(id)) === "published" ? { status: "LIVE", name: f.name } : refused("zone_unavailable");
  }

  private async needsReview(f: GrowFields, isLive: boolean, origin: GrowOrigin): Promise<boolean> {
    if (!isLive || origin === "untrusted" || this.d.store.listGrowUndoReasons(f.name).length > 0) return true;
    const prev = parseSkillFile((await this.d.zone.readHead(f.name)) ?? "");
    return prev === null || !isSmallUpdate(prev, f);
  }

```ts
  publishStaged(id: number): Promise<"published" | "retry" | "disabled" | "gone"> {
    return this.locked(() => this.publishLocked(id), "retry" as const);
  }

  /** Spec §5.8: publishing row → file → commit → live item. Each step is safe to repeat. */
  private async publishLocked(id: number): Promise<"published" | "retry" | "disabled" | "gone"> {
    const { store, zone } = this.d;
    const row = store.getGrowStaged(id);
    if (!row || row.state === "failed") return "gone";
    const firstTry = row.state !== "publishing";
    store.patchGrowStaged(id, { state: "publishing", claimed_at: null }, this.d.now());
    const f = JSON.parse(row.fields_json) as GrowFields;
    try {
      const at = parseSkillFile((await zone.readHead(row.name)) ?? "");
      const commit = at && contentHash(at) === row.content_hash && at.origin === row.origin
        ? await zone.head()
        : await zone.writeAndCommit(row.name, renderSkillFile(f, row.origin), `skill(${row.name}): ${store.getGrowItem(row.name)?.state === "live" ? "update" : "add"}\n\nContent-Hash: ${row.content_hash}\nRun: ${row.run_id ?? "-"}`);
      this.finishPublish(row, f, commit);
      return "published";
    } catch {
      await zone.restoreToHead().catch(() => undefined);
      if (firstTry) return "retry";
      this.disable("grow_publish_failed", row.name);
      return "disabled";
    }
  }

  private finishPublish(row: GrowStagedRow, f: GrowFields, commit: string): void {
    const { store } = this.d; const now = this.d.now();
    const added = store.getGrowItem(row.name)?.state !== "live";
    store.inTransaction(() => {

  readReview(name: string): { ok: true; text: string } | { ok: false; code: "no_review" } {
    const row = this.d.store.listGrowStaged("failed").filter((r) => r.name === name).at(-1);
    if (!row) return { ok: false, code: "no_review" };
    const findings = (JSON.parse(row.findings_json ?? "[]") as Array<{ step: string; problem: string }>).map((x) => `- ${x.step}: ${x.problem}`);

  undo(name: string, reason: string | null): Promise<{ ok: true; removed: boolean } | { ok: false; code: "unknown_skill" | "is_exemplar" | "busy" | "zone_unavailable" }> {
    return this.locked(async () => {
      const { store, zone } = this.d; const now = this.d.now();
      const item = store.getGrowItem(name);
      if (!item || item.state !== "live") return { ok: false as const, code: "unknown_skill" as const };
      if (item.origin === "exemplar") return { ok: false as const, code: "is_exemplar" as const };
      try {
        const prev = parseSkillFile((await zone.previousVersion(name)) ?? "");
        const commit = prev ? await zone.writeAndCommit(name, renderSkillFile(prev, prev.origin), `skill(${name}): undo`) : await zone.removeAndCommit(name, `skill(${name}): undo (removed)`);
        store.inTransaction(() => {
          if (prev) store.upsertGrowItem({ name, state: "live", origin: item.origin, description: prev.description, example: prev.example, head_commit: commit, content_hash: contentHash(prev) }, now);
          else store.setGrowItemState(name, "removed", now);
          if (reason) store.addGrowUndoReason(name, reason.slice(0, 500), now);
          else store.addGrowUndoReason(name, "(no reason given)", now);
          store.appendGrowEvent({ at: now, run_id: null, chat_id: null, name, action: "undo", result: prev ? "restored" : "removed", code: null, reviewer_model: null, commit_id: commit });
        });
        store.enqueueNotification({ topic: "grow_log", idempotency_key: `grow:undo:${commit}:${name}`, correlation_id: `grow:${name}`, text: `Paco undid the skill ${name}.`, now });
        return { ok: true as const, removed: !prev };
      } catch { return { ok: false as const, code: "zone_unavailable" as const }; }
    }, { ok: false as const, code: "busy" as const });
  }

  trust(name: string): boolean {
    const item = this.d.store.getGrowItem(name);
    if (!item || item.origin !== "untrusted") return false;
    this.d.store.setGrowItemOrigin(name, "clean", this.d.now());
    this.d.store.appendGrowEvent({ at: this.d.now(), run_id: null, chat_id: null, name, action: "trust", result: "clean", code: null, reviewer_model: null, commit_id: null });
    return true;
  }

export function buildReviewPrompt(i: ReviewInput): string {
  const f = i.fields;
  const item = `name: ${f.name}\ndescription: ${f.description}\nexample: ${f.example}\n${(f.anchors ?? []).map((a) => `anchor: ${a}`).join("\n")}\n\n${f.body}`;
  return [RULES, block("ITEM", item),
    ...(i.previous ? [block("PREVIOUS_VERSION", i.previous.body)] : []),
    ...(i.undoReasons.length > 0 ? [block("UNDO_REASONS", i.undoReasons.join("\n"))] : []),
    block("LIVE_INDEX", i.index || "(empty)"), block("EXEMPLAR_OF_GOOD_SHAPE", i.exemplar)].join("\n\n");
}

export function parseReview(answer: string): ReviewVerdict | null {
  const raw = extractFirstJsonObject(answer);
  if (!raw) return null;
  let v: unknown;
  try { v = JSON.parse(raw); } catch { return null; }
  const o = v as { pass?: unknown; findings?: unknown };
  if (typeof o.pass !== "boolean" || !Array.isArray(o.findings)) return null;
  const findings = o.findings.map((x) => x as { step?: unknown; problem?: unknown });
  if (findings.some((x) => typeof x.step !== "string" || typeof x.problem !== "string")) return null;
  return { pass: o.pass, findings: findings.slice(0, 20).map((x) => ({ step: String(x.step).slice(0, 80), problem: String(x.problem).slice(0, 400) })) };
}

export function reviewerChain(chain: ModelString[], authorFamilies: string[]): ModelString[] {
  return chain.filter((m) => !authorFamilies.includes(familyOf(m)));
}

export async function runReview(i: ReviewInput & { authorFamilies: { families: string[]; unknown: boolean }; chain: ModelString[]; correlationId: string; signal?: AbortSignal; scrub: (s: string) => string },
  deps: { spawn: (input: OneShotInput) => Promise<LlmResult> }): Promise<ReviewOutcome> {
  if (i.authorFamilies.unknown) return { kind: "unavailable", reason: "no_family" };
  const chain = reviewerChain(i.chain, i.authorFamilies.families);
  if (chain.length === 0) return { kind: "unavailable", reason: "no_reviewer" };
  const prompt = i.scrub(buildReviewPrompt(i));
  const r = await deps.spawn({ seat: "grow_review", chain, prompt, correlationId: i.correlationId, ...(i.signal ? { signal: i.signal } : {}) });
  if (!r.ok) return { kind: "unavailable", reason: "seat_failed" };
  const verdict = parseReview(r.answer);
  if (!verdict) return { kind: "unavailable", reason: "bad_json" };
  return { kind: "verdict", verdict, model: `${r.provider}/${r.model}`, inputHash: createHash("sha256").update(prompt).digest("hex") };
}

```ts
import type { OneShotInput } from "../llm/providers/omp.js";
import type { LlmResult } from "../llm/types.js";
import type { ModelString } from "../omp/model-string.js";
import { redactForImprove } from "../decisions/egress.js";
import type { GrowStagedRow, RunStore } from "../run/run-store.js";
import { type GrowFields, parseSkillFile } from "./checks.js";
import { resolveGrowEnabled } from "./flags.js";
import { runReview } from "./review.js";
import type { GrowService } from "./service.js";
import type { GrowZone } from "./zone.js";

export const GROW_CLAIM_STALE_MS = 10 * 60_000;
export const GROW_RETRY_AFTER_MS = [3_600_000, 21_600_000, 86_400_000] as const;
export interface GrowTickDeps { store: RunStore; svc: GrowService; zone: GrowZone; env: NodeJS.ProcessEnv; now: string; signal: AbortSignal;
  chain: () => ModelString[]; spawn: (input: OneShotInput) => Promise<LlmResult>; exemplar: () => Promise<string>; settled: (run_id: string) => boolean }
const plus = (iso: string, ms: number): string => new Date(Date.parse(iso) + ms).toISOString();

/** One poll cycle's grow work (spec §5.4, §5.8): finish publishes in flight, release stale claims, then at most one review. */
export async function runGrowTick(d: GrowTickDeps): Promise<{ reconciled: boolean; reviewed: number | null }> {
  await d.svc.reconcile();
  d.store.releaseStaleGrowClaims(plus(d.now, -GROW_CLAIM_STALE_MS));
  if (!resolveGrowEnabled(d.env) || d.signal.aborted) return { reconciled: true, reviewed: null };
  const row = d.store.dueGrowReviews(d.now).find((r) => r.run_id === null || d.settled(r.run_id));
  if (!row || !d.store.claimGrowReview(row.id, d.now)) return { reconciled: true, reviewed: null };
  await reviewOne(d, row);
  return { reconciled: true, reviewed: row.id };
}

async function reviewOne(d: GrowTickDeps, row: GrowStagedRow): Promise<void> {
  const attempt = row.attempts + 1;   // claimGrowReview already bumped the stored count
  const families = row.run_id ? d.store.runAuthorFamilies(row.run_id) : { families: [], unknown: true };
  const fields = JSON.parse(row.fields_json) as GrowFields;
  const outcome = await runReview({
    fields, previous: parseSkillFile((await d.zone.readHead(row.name)) ?? ""), exemplar: await d.exemplar(), index: d.svc.indexBlock() ?? "",
    undoReasons: d.store.listGrowUndoReasons(row.name).map((r) => r.reason), authorFamilies: families, chain: d.chain(),
    correlationId: `grow_review:${row.id}:${attempt}`, signal: d.signal, scrub: (s) => redactForImprove(d.store, s)
  }, { spawn: d.spawn });
  if (outcome.kind === "unavailable") return unavailable(d, row, attempt, families.families);
  d.store.patchGrowStaged(row.id, { author_families: families.families.join(","), review_input_hash: outcome.inputHash, claimed_at: null }, d.now);
  if (outcome.verdict.pass) { await d.svc.publishStaged(row.id); return; }
  d.store.patchGrowStaged(row.id, { state: "failed", code: "review_failed", findings_json: JSON.stringify(outcome.verdict.findings) }, d.now);
  d.store.appendGrowEvent({ at: d.now, run_id: row.run_id, chat_id: row.chat_id, name: row.name, action: "review_failed", result: "failed", code: "review_failed", reviewer_model: outcome.model, commit_id: null });
}

function unavailable(d: GrowTickDeps, row: GrowStagedRow, attempt: number, families: string[]): void {
  const wait = GROW_RETRY_AFTER_MS[attempt - 1];
  if (wait !== undefined) { d.store.patchGrowStaged(row.id, { claimed_at: null, next_attempt_at: plus(d.now, wait), author_families: families.join(",") }, d.now); return; }
  d.store.patchGrowStaged(row.id, { state: "failed", code: "review_unavailable", claimed_at: null }, d.now);
  d.store.appendGrowEvent({ at: d.now, run_id: row.run_id, chat_id: row.chat_id, name: row.name, action: "review_failed", result: "failed", code: "review_unavailable", reviewer_model: null, commit_id: null });
}
```

`dueGrowReviews` returns rows read before the claim, so `row.attempts` is the count before this attempt; that is why `attempt = row.attempts + 1`. A publish after a passing review carries the reviewing model only in the ledger's `llm_attempt` row; that is enough for the live gate.

import { existsSync, readdirSync, readFileSync, renameSync } from "node:fs";
import { dirname, join } from "node:path";
import type { RunStore } from "../run/run-store.js";
import { type GrowFields, checkFields, contentHash, parseSkillFile, renderSkillFile } from "./checks.js";
import type { GrowService } from "./service.js";

/** Boot step (spec §5.11): publish a missing or changed exemplar after the formal checks; a failing one is reported, never published. */
export async function seedExemplars(d: { store: RunStore; zone: GrowZone; seedDir: string; now: string; scrub: (s: string) => string }): Promise<{ seeded: string[]; failed: string[] }> {
  const root = join(d.seedDir, "skills");
  const seeded: string[] = []; const failed: string[] = [];
  for (const name of existsSync(root) ? readdirSync(root).sort() : []) {
    const f = parseSkillFile(readFileSync(join(root, name, "SKILL.md"), "utf8"));
    const others = d.store.listGrowItems("live").filter((i) => i.name !== name);
    if (!f || f.name !== name || !checkFields(f, others, d.scrub).ok) { failed.push(name); continue; }
    const hash = contentHash(f);
    if (d.store.getGrowItem(name)?.content_hash === hash) continue;
    const commit = await d.zone.writeAndCommit(name, renderSkillFile(f, "exemplar"), `skill(${name}): seed exemplar`);
    d.store.upsertGrowItem({ name, state: "live", origin: "exemplar", description: f.description, example: f.example, head_commit: commit, content_hash: hash }, d.now);
    d.store.appendGrowEvent({ at: d.now, run_id: null, chat_id: null, name, action: "seed", result: "ok", code: null, reviewer_model: null, commit_id: commit });
    seeded.push(name);
  }
  return { seeded, failed };
}

/** The old layout's frontmatter: `name`, `when`, optional `anchors` list of plain lines. */
function parseLegacy(text: string): GrowFields | null {
  const m = /^---\n([\s\S]*?)\n---\n+([\s\S]*)$/.exec(text);
  if (!m) return null;
  const line = (k: string): string | undefined => new RegExp(`^${k}: (.*)$`, "m").exec(m[1]!)?.[1]?.trim();
  const name = line("name"); const when = line("when");
  if (!name || !when) return null;
  const anchors = [...m[1]!.matchAll(/^ {2}- (.*)$/gm)].map((x) => x[1]!.trim()).filter((a) => a.length <= 300).slice(0, 8);
  const description = when.slice(0, 200);
  return { name, description, example: `a request about ${description}`.slice(0, 300), body: m[2]!.trim().slice(0, 8000), ...(anchors.length > 0 ? { anchors } : {}) };
}

/** One-shot, idempotent (spec §5.11): the skills Paco accepted under the old gate become live clean items; the folder is renamed. */
export async function migrateLegacySkills(d: { store: RunStore; svc: GrowService; zone: GrowZone; legacyDir: string; now: string }): Promise<{ migrated: string[]; skipped: string[] }> {
  const migrated: string[] = []; const skipped: string[] = [];
  if (!existsSync(d.legacyDir)) return { migrated, skipped };
  for (const scope of readdirSync(d.legacyDir, { withFileTypes: true }).filter((e) => e.isDirectory() && !e.name.startsWith("_"))) {
    for (const file of readdirSync(join(d.legacyDir, scope.name)).filter((n) => n.endsWith(".md")).sort()) {
      const f = parseLegacy(readFileSync(join(d.legacyDir, scope.name, file), "utf8"));
      if (!f || !/^[a-z0-9-]{3,48}$/.test(f.name) || d.store.getGrowItem(f.name)) { skipped.push(file); continue; }
      const commit = await d.zone.writeAndCommit(f.name, renderSkillFile(f, "clean"), `skill(${f.name}): migrate from skills/${scope.name}`);
      d.store.upsertGrowItem({ name: f.name, state: "live", origin: "clean", description: f.description, example: f.example, head_commit: commit, content_hash: contentHash(f) }, d.now);
      d.store.appendGrowEvent({ at: d.now, run_id: null, chat_id: null, name: f.name, action: "migrate", result: "ok", code: null, reviewer_model: null, commit_id: commit });
      migrated.push(f.name);
    }
  }
  renameSync(d.legacyDir, join(dirname(d.legacyDir), `skills.migrated-${d.now.slice(0, 7)}`));
  return { migrated, skipped };
}
